# 🇦🇲 Агрегатор вакансий Армении

Автоматический сборщик вакансий со всех крупных сайтов Армении с переводом на русский,
Excel-выгрузкой, Telegram-уведомлениями и веб-дашбордом на GitHub Pages.

## Что делает

| Источник | Что собирает | Статус |
|---|---|---|
| [staff.am](https://staff.am) | Все активные вакансии (~1200, 25 страниц) | ✅ работает |
| [worknet.am](https://worknet.am) | Все активные вакансии (частные + гос., через открытый API) | ✅ работает |
| [list.am](https://www.list.am/category/79) | Раздел вакансий («армянский Авито») | ⚠️ best-effort |
| [hire.am](https://hire.am) | — | ❌ домен не отвечает |

Что происходит при каждом запуске (по крону 3 раза в день):

1. **Сбор** всех вакансий со всех источников (без фильтров: от курьера до IT).
2. **Перевод** армянских названий на русский (Google Translate, с постоянным кэшем —
   повторные запуски переводят только новинки).
3. **Excel** — `output/vacancies.xlsx` (лист «Вакансии» + сводка, свежие сверху, фильтры).
4. **Дашборд** — `output/index.html` публикуется на GitHub Pages: поиск, фильтры,
   сортировка, кнопка «Скачать Excel».
5. **Telegram** — бот присылает только **новые** вакансии с прошлого запуска.

## Развёртывание: 4 шага

### Шаг 1. Telegram-бот

1. В Telegram найдите **@BotFather** → команда `/newbot` → задайте имя и юзернейм.
2. BotFather выдаст **токен** вида `1234567:AAEhBOweik6ad9r_QXEN...` — сохраните.
3. Узнайте свой **chat_id**: напишите боту любое сообщение, затем откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе найдите `"chat":{"id":123456789,...}`.
   (Или напишите боту **@userinfobot** — он пришлёт ваш id.)
4. **Напишите своему боту первое сообщение** (кнопка Start) — иначе он не сможет вам писать.

> Хотите бот в группу/канал — добавьте бота админом и возьмите chat_id группы
> (для каналов id вида `-100...`).

### Шаг 2. Секреты репозитория

`Settings` → `Secrets and variables` → `Actions` → `New repository secret`:

| Name | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | ваш chat_id |

### Шаг 3. Включить GitHub Pages

`Settings` → `Pages` → **Build and deployment → Source: выберите `GitHub Actions`**.

Это единственная настройка Pages, которая нужна — workflow сам соберёт и опубликует дашборд.

### Шаг 4. Первый запуск

`Actions` → **Сбор вакансий** → `Run workflow` → `Run workflow`.

Через 2–4 минуты:
- 📊 дашборд появится на `https://<ваш_логин>.github.io/<имя_репо>/`
- 📦 Excel можно скачать с дашборда (кнопка «⬇ Excel»)
- 🤖 бот пришлёт все вакансии первого запуска (до 30 сообщений, дальше — только новинки)

Дальше всё работает само: крон `0 5,11,17 * * *` UTC (09:00 / 15:00 / 21:00 по Еревану).

## Локальный запуск

```bash
pip install -r requirements.txt

# без Telegram — просто собрать Excel и дашборд:
python main.py

# с Telegram:
TELEGRAM_BOT_TOKEN="123:ABC" TELEGRAM_CHAT_ID="123456" python main.py
```

Результат: `output/vacancies.xlsx` и `output/index.html`.

## Настройки (необязательно)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `STAFF_MAX_PAGES` | 30 | сколько страниц staff.am обходит (50 вакансий/стр) |
| `LIST_MAX_PAGES` | 3 | страниц list.am за прогон (сайт за Cloudflare, трогаем бережно) |
| `TG_PER_MESSAGE` | 10 | вакансий в одном Telegram-сообщении |
| `TG_MAX_MESSAGES` | 30 | максимум сообщений за прогон |
| `SLEEP_BETWEEN_REQUESTS` | 1.0 | пауза между запросами, сек |

Расписание меняется в `.github/workflows/update.yml` (поле `cron`, время в UTC).

## Важные нюансы

- **worknet.am из GitHub Actions.** Их API блокирует датацентровые IP Azure (где крутятся
  Actions-раннеры) с кодом 403 — источник может отдавать 0 вакансий в облаке. Локальный запуск
  с домашнего/офисного IP работает. Основной объём в облаке даёт staff.am (1200+ вакансий).
- **list.am и Cloudflare.** list.am закрыт Cloudflare и блокирует запросы с датацентровых IP.
  Парсер честно пытается (cloudscraper), и если не вышло — пропускает источник, не ломая остальное.
- **hire.am** на момент создания проекта не отвечает (домен не резолвится). Скрапер оставлен:
  если сайт оживёт — источник подключится сам.
- **Состояние «что уже показано»** хранится в `state/seen.json` и коммитится ботом в репозиторий —
  поэтому дельта «только новые» работает между запусками без внешней БД.
- **Кэш переводов** в `data/translations_cache.json` — тоже в репозитории: Google Translate
  дёргается только для новых должностей.

```
├── main.py                  # конвейер: сбор → перевод → excel → дашборд → TG

│   │   └── hire_am.py       #   hire.am (резерв на будущее)
│   ├── translate.py         # арм→рус с постоянным кэшем
│   ├── storage.py           # state/seen.json + data/latest.json
│   ├── excel.py             # vacancies.xlsx
│   ├── dashboard.py         # index.html для GitHub Pages
│   └── telegram_notify.py   # уведомления о дельте

├── state/seen.json          # какие вакансии уже отправлялись
└── data/                    # кэш переводов, срез вакансий
```

## Частые вопросы

**Бот не присылает вакансии.** Проверьте: (1) секреты заданы точно с такими именами;
(2) вы нажали Start в чате с ботом; (3) во вкладке Actions последний запуск зелёный —
в его Step Summary видно счётчики; (4) новых вакансий могло просто не быть.

**Pages отдаёт 404.** Убедитесь, что в `Settings → Pages` выбран Source = `GitHub Actions`,
и что workflow завершился успешно хотя бы раз.

**Хочу другой график.** Отредактируйте `cron` в `.github/workflows/update.yml`.
Помните: cron в UTC, Ереван = UTC+4, Москва = UTC+3.

**Вакансия продублировалась.** Дедупликация по внутреннему id сайта. Один и тот же работодатель
на разных площадках — это два разных id, так и задумано.
